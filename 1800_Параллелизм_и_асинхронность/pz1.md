# Практическое задание

## Тема

Сравнение `threading`, `multiprocessing` и `asyncio` на практике

# Цель

Написать три версии программы, которые решают схожую задачу с использованием разных подходов конкурентного выполнения:

- `threading`
- `multiprocessing`
- `asyncio`

В процессе выполнения задания необходимо понять:

- как создаются потоки;
- как создаются процессы;
- как работают корутины;
- в каких случаях каждый подход показывает свои преимущества;
- чем отличаются результаты и время выполнения.

# Задание (шаги)

Необходимо реализовать программу, которая выполняет пять независимых задач.

Каждая задача должна:

1. Получать свой номер.
2. Выводить сообщение о начале работы.
3. Имитировать длительную операцию ожидания продолжительностью 2 секунды.
4. Выводить сообщение о завершении работы.

Например:

```text
Задача 1 началась
Задача 2 началась
...
Задача 1 завершена
```

## Часть 1. Реализация через threading

Создайте функцию:

```python

```

Для каждой задачи создайте отдельный поток.

Все потоки должны запускаться практически одновременно.

После запуска дождитесь завершения всех потоков.

В конце программы выведите сообщение:

```text

```

Замерьте время выполнения всей программы.

Для измерения времени можно использовать:

```python
import time
```

и функции:

```python
time.time()
```

или

```python

```

Сохраните результат времени выполнения.

## Часть 2. Реализация через multiprocessing

Вместо потоков используйте процессы.

Каждая задача должна выполняться в отдельном процессе.

После завершения всех процессов выведите:

Также измерьте время выполнения.

Сравните результат с вариантом на потоках.

## Часть 3. Реализация через asyncio

# Подсказки по ключевым частям

Для создания потока используется:

```python
thread = threading.Thread(target=worker, args=(task_id,))
```

Запуск потока:

```python
thread.start()
```

Ожидание завершения:

```python
thread.join()
```

Для создания процесса используется:

```python
process = multiprocessing.Process(target=worker, args=(task_id,))
```

Запуск процесса:

```python
process.start()
```

Ожидание завершения:

```python
process.join()
```

При работе с `multiprocessing` не забывайте использовать:

```python
if __name__ == "__main__":
```

Иначе программа может работать некорректно.

Для создания корутины используется:

```python
async def worker(): ...
```

Асинхронное ожидание:

```python
await asyncio.sleep(2)
```

Запуск программы:

```python
asyncio.run(main())
```

Одновременный запуск нескольких корутин:

```python
await asyncio.gather(...)
```

Для измерения времени выполнения удобно использовать:

```python
start = time.perf_counter()

# код

end = time.perf_counter()

print(end - start)
```

# Что проверить перед отправкой (чек-лист)

Убедитесь, что программа на `threading` создает именно потоки, а не просто вызывает функцию напрямую.

Убедитесь, что программа на `multiprocessing` запускает отдельные процессы.

Убедитесь, что в асинхронной версии используется `await asyncio.sleep()`, а не `time.sleep()`.

Проверьте, что все задачи действительно запускаются одновременно.

Проверьте наличие замеров времени выполнения.

Проверьте, что после завершения всех задач выводится итоговое сообщение.

Проверьте, что в версии с `multiprocessing` присутствует блок:

```python
if __name__ == "__main__":
```

Проверьте, что код соответствует требованиям PEP 8.

Проверьте, что программа запускается без ошибок.

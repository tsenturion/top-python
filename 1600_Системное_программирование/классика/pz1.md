# Практическое задание: работа с `os`, `sys` и `pathlib`

## Цель

Научиться:

- работать с файловой системой через `os`;
- получать аргументы командной строки через `sys`;
- использовать объектный подход к путям через `pathlib`;
- создавать, проверять и анализировать файлы и директории;
- комбинировать несколько стандартных модулей в одной программе.

# Задание

Необходимо написать консольную программу «Анализатор директории».

Программа должна запускаться из терминала и принимать путь к папке через аргументы командной строки.

Пример запуска:

```bash
python main.py ./test_folder
```

# Что должна делать программа

## Шаг 1. Получить путь из командной строки

Используйте `sys.argv`.

Программа должна:

- проверить, передан ли путь;
- вывести сообщение об ошибке, если путь отсутствует;
- завершить программу корректно.

Пример:

```bash
python main.py
```

Результат:

```python
Путь к директории не передан
```

## Шаг 2. Проверить существование директории

Используйте `pathlib.Path`.

Нужно проверить:

- существует ли путь;
- является ли путь директорией.

Если директория не существует — вывести сообщение.

Пример:

```python
Директория не найдена
```

## Шаг 3. Вывести общую информацию о папке

Программа должна показать:

- абсолютный путь;
- имя директории;
- количество файлов;
- количество вложенных папок.

## Шаг 4. Найти все файлы внутри директории

Используйте:

- `os.walk()`
  или
- `Path.rglob()`.

Необходимо:

- вывести список всех файлов;
- показать расширение каждого файла;
- показать размер файла в байтах.

Пример вывода:

```python
Файл: report.txt
Расширение: .txt
Размер: 2048 байт
```

## Шаг 5. Создать отчет

Программа должна создать файл:

```python
report.txt
```

В отчете сохранить:

- путь к директории;
- список файлов;
- размеры файлов;
- общее количество файлов;
- общее количество папок.

## Шаг 6. Создать папку results

Если папки `results` нет — создать ее.

Внутри нее сохранить отчет.

Структура после выполнения:

```python
project/
│
├── main.py
├── results/
│   └── report.txt
```

## Шаг 7. Добавить обработку ошибок

Нужно обработать:

- отсутствие аргументов;
- неверный путь;
- ошибки доступа к файлам;
- ошибки чтения директорий.

Используйте:

```python
try:
except:
```

# Подсказки по ключевым частям

## Получение аргументов

```python
import sys

print(sys.argv)
```

`sys.argv` — список аргументов командной строки.

## Работа с путями через pathlib

```python
from pathlib import Path

path = Path("test_folder")
```

Проверка существования:

```python
path.exists()
```

Проверка, что это папка:

```python
path.is_dir()
```

Получение абсолютного пути:

```python
path.resolve()
```

## Создание директории

```python
results_dir.mkdir(exist_ok=True)
```

## Получение файлов рекурсивно

```python
path.rglob("*")
```

или

```python
os.walk(path)
```

## Размер файла

```python
file.stat().st_size
```

## Запись в файл

```python
with open("report.txt", "w", encoding="utf-8") as file:
    file.write("Текст")
```

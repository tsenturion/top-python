### Практическое задание: «Генератор отчетов по продажам»

**Цель:** Научиться преобразовывать циклы `for` в лаконичные и эффективные `list comprehension`, применять условную фильтрацию (`if-else`), вложенные конструкции и обработку исключений в рамках одного выражения.

### Задание (шаги)

Вы — аналитик в интернет-магазине. У вас есть "грязный" список данных о продажах за день. Ваша задача — с помощью `list comprehension` создать несколько отчетов.

**Исходные данные (скопируйте в начало своего скрипта):**

```python
sales_data = [
    "1200",
    "отмена",
    "750",
    "ERROR",
    "450",
    "0",
    "3000",
    "отмена",
    "890",
    "invalid",
]
```

**Шаг 1. Очистка данных**
Создайте список `clean_sales`, который содержит только корректные числовые значения (как целые числа) из `sales_data`. Строки, которые нельзя преобразовать в число, должны игнорироваться.

**Шаг 2. Применение скидки**
Создайте список `sales_with_discount`. Для всех чисел из `clean_sales` примените правило:

- Если сумма покупки >= 1000, новая цена = сумма \* 0.9 (скидка 10%)
- Иначе цена остается без изменений.
  _Используйте тернарный оператор внутри list comprehension._

**Шаг 3. Бонусные баллы (Маркировка)**
Создайте список `sales_status`. Для чисел из `clean_sales` верните строку:

- `"high"` — если сумма > 2000
- `"medium"` — если 500 <= сумма <= 2000
- `"low"` — если сумма < 500

**Шаг 4. Трансформация "грязных" данных (Продвинутый уровень)**
Создайте список `processed_data`, который обрабатывает **каждый** элемент исходного `sales_data`:

- Если значение — числовая строка (например, "1200"), преобразуйте его в `int`
- Если значение — `"отмена"`, замените на `-1`
- В остальных случаях (ошибки, invalid) замените на `0`

**Шаг 5. Генерация квадратов четных чисел (Самостоятельно)**
Используя `range(1, 11)`, создайте список квадратов только **четных** чисел от 1 до 10.
_Пример результата: [4, 16, 36, 64, 100]_

### Подсказки по ключевым частям

1.  **Проверка на число (Шаг 1):**
    В `list comprehension` можно использовать метод `.isdigit()`, но помните, что он не сработает с отрицательными числами. Для нашего случая (положительные числа и "0") он подходит:

    ```python
    [int(x) for x in sales_data if x.isdigit()]
    ```

    _Альтернатива (защита от ошибок):_ используйте `try/except` внутри отдельной функции, но в `list comprehension` это нельзя встроить напрямую (на этом этапе учимся фильтровать).

2.  **Тернарный оператор (Шаг 2):**
    Синтаксис: `[значение_если_True if условие else значение_если_False for элемент in коллекция]`

    ```python
    [price * 0.9 if price >= 1000 else price for price in clean_sales]
    ```

3.  **Множественные условия (Шаг 3):**
    Используйте цепочку `if` ... `elif` ... `else` внутри `list comprehension`. Синтаксис не самый красивый, но рабочий:

    ```python
    ["high" if x > 2000 else "medium" if 500 <= x <= 2000 else "low" for x in clean_sales]
    ```

4.  **Трансформация с условиями (Шаг 4):**
    Здесь у нас есть **и преобразование, и замена**. Фильтрация не подходит (мы не удаляем элементы, мы меняем их). Используйте цепочку `if-elif-else` в начале выражения.
    _Совет:_ сначала проверяйте на `"отмена"`, потом на `.isdigit()`.

### Что проверить перед отправкой (чек-лист)

- [ ] Результат `clean_sales` — это список из целых чисел (тип `int`), содержащий: `[1200, 750, 450, 0, 3000, 890]`. Ошибки и "отмена" удалены.
- [ ] Результат `sales_with_discount` — для 3000 стало 2700.0, для 1200 стало 1080.0, для 750 осталось 750.
- [ ] Результат `sales_status` содержит строки `"high"`, `"medium"`, `"low"` в правильном порядке. 3000 → `"high"`, 750 → `"medium"`, 450 → `"low"`.
- [ ] Результат `processed_data` имеет **ту же длину**, что и исходный список (9 элементов). Например: `[1200, -1, 750, 0, 450, 0, 3000, -1, 890, 0]`.
- [ ] Результат квадратов четных чисел выводится без использования стандартного цикла `for` (только `list comprehension`).

### Советы по улучшению работы

1.  **Не злоупотребляйте.** Если `list comprehension` становится длиннее 3-х условий или содержит вложенные циклы (например, `[x for y in matrix for x in y]` — норма, но сложнее — нет), лучше написать обычный цикл `for` для читаемости.
2.  **Именование.** Не называйте переменную `list`, чтобы не переопределять встроенный класс.
3.  **Производительность.** List comprehension работает быстрее `for` + `append` для больших данных (до 20-30% выигрыша). Это отличная привычка для обработки логов или CSV.
4.  **Документирование.** Если логика сложная, добавьте короткий комментарий над строкой `list comprehension`. Коллеги скажут спасибо.
5.  **Альтернатива для Шага 1.** Изучите функцию `str.isdecimal()` — она строже, чем `isdigit()` (не пропускает римские цифры и дроби). Для финансовых данных это плюс.

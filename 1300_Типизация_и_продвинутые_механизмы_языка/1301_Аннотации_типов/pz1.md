# Практическое задание

## Тема

Типизация в Python 3.12+ без использования модуля `typing`

# Цель

Разработать небольшую систему управления каталогом книг с использованием современных возможностей аннотаций типов Python 3.12+.

В процессе выполнения задания необходимо показать уверенное владение встроенными средствами типизации, включая:

- аннотации переменных;
- аннотации параметров функций;
- аннотации возвращаемых значений;
- объединение типов через оператор `|`;
- типизированные коллекции;
- вложенные типизированные структуры данных;
- использование `type` для создания псевдонимов типов;
- применение типов в классах и методах.

Использование модуля `typing` запрещено.

# Подсказки по ключевым частям

Для объединения нескольких типов в Python 3.12+ используется оператор:

```python
str | int
```

а не:

```python
Union[str, int]
```

Для необязательного значения используется:

```python
BookInfo | None
```

а не:

```python
Optional[BookInfo]
```

Для типизированного списка используется:

```python
list[str]
```

Для типизированного словаря используется:

```python
dict[str, int]
```

Для создания собственного псевдонима типа применяется ключевое слово:

```python
type UserId = int
```

Все поля класса также должны иметь аннотации:

```python
self.books: list[BookInfo]
```
